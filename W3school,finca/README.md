فقط یک اصلاح مهم: چیزی که درباره W3Schools پیدا کردم، یک **نسخه آفلاین غیررسمی روی GitHub** است؛ مثلاً مخزن `ja7ad/W3Schools` نسخه‌های آفلاین و Release دارد و مخزن دیگری هم نسخه فشرده آفلاین ارائه می‌کند. بنابراین در ویدیو نگو «خود W3Schools این فایل رو منتشر کرده» مگر اینکه دقیقاً همان منبع رسمی را داشته باشی. # ⏱️ 18–38 ثانیه — فینکا

اینجا می‌خوام فینکا رو **تبلیغاتی و مصنوعی معرفی نکنی.**

بگو:

> «ولی اگه لپ‌تاپ هم همراهت نیست، یه گزینه خیلی کاربردی دیگه هست.»

Cut.

صفحه گوشی → فینکا.

> «فینکا.»

بعد:

> «یه اپلیکیشن فارسیه که می‌تونی با گوشی هم برنامه‌نویسی یاد بگیری.»

بعد سریع چند تصویر از محیطش:

**Lesson → Code → Exercise**

و بگو:

> «درس رو می‌بینی، همون‌جا تمرین می‌کنی و بعد می‌ری سراغ مرحله بعد.»

این قسمت واقعاً با امکانات فعلی فینکا همخوانی داره؛ توضیحات رسمی اپ به آموزش مرحله‌ای و تمرین مرتبط بعد از هر درس اشاره می‌کند. ([Google Play][2])

> «پس حتی اگه لپ‌تاپ نداشته باشی، می‌تونی یادگیری رو ادامه بدی.»
