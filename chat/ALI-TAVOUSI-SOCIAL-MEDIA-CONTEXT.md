# 19. پست دوم

ایده فعلی برای پست دوم:

### Bootstrap

موضوع:

> «اگر تازه Front-end رو شروع کردی، Bootstrap یکی از چیزهاییه که به نظرم ارزش داره بعد از HTML و CSS یاد بگیری.»

نمی‌خواهیم ادعا کنیم:

> «هر Front-end Developer حتماً باید Bootstrap یاد بگیرد.»

چون Bootstrap ضروری نیست.

ایده اصلی Reel:

**مقایسه CSS خام با Bootstrap**

مثلاً:

CSS:

```css
.button {
  padding: 12px 24px;
  background: #0d4370;
  color: white;
  border: none;
  border-radius: 8px;
}
```

Bootstrap:

```html
<button class="btn btn-primary">
  Click me
</button>
```

و چند مثال دیگر مثل Flexbox / Centering.

نکته مهم:

نباید عمداً CSS را غیرواقعی و بیش از حد طولانی کنیم تا Bootstrap برنده به نظر برسد.

باید مقایسه واقعی و منصفانه باشد.

همچنین حتماً بگوییم:

> **Bootstrap جای HTML و CSS را نمی‌گیرد؛ بهتر است اول HTML و CSS را یاد بگیری تا بفهمی Bootstrap چه کاری برایت انجام می‌دهد.**
